# @hackathon-atlas/cli

Local keyword search over a SQLite FTS5 index generated by `@hackathon-atlas/catalog-index`, and analogue lookup over a caller-supplied catalog JSON file. The index is generated. It is not the canonical catalog.

Neither command calls a language model or uses a vector database. Neither command creates catalog records or invents projects.

## Commands

```text
hackathon-atlas search --index <generated.sqlite> [--filter field=value] <keywords>
hackathon-atlas analogues --catalog <catalog.json> --mode <direct|mechanism|demo> --project <id>
hackathon-atlas analogues --catalog <catalog.json> --mode <direct|mechanism|demo> --title <exact project name>
```

`--filter` may be repeated. A filter is applied only when its field is a column of the generated `records` table. If the column is absent, the filter is not applied and the JSON result lists that filter as `status: "unknown"`.

`hitCounts.real` counts matching rows stored with `synthetic` false. Rows stored with `synthetic` true are counted only in `hitCounts.synthetic`. If the index has no `synthetic` column, both counts are `null` with `status: "unknown"`, and those rows are not reported as real. A stored flag is not, by itself, evidence that a row is a genuine hackathon project.

This package commits no catalog fixture. Tests build a temporary index and delete it. The catalog-index fixture it reads is labeled synthetic.

## Analogues

`analogues` reads the catalog JSON file given by `--catalog` and calls `retrieveAnalogues` from `@hackathon-atlas/analogues`. It does not read the SQLite index and does not fetch.

`--mode` is required. The modes are `direct`, `mechanism`, and `demo`. The subject is either `--project` (exact project id) or `--title` (exact project name). If the title matches more than one project, the command exits with a usage error and lists those ids. It does not pick one. If the title matches none, the JSON status is `unknown`.

The printed JSON has `status`, `reason` when the result has one, and each analogue's project id, synthetic label, and shared text. It does not print precision, recall, or a recommendation. Unknown stays unknown. Synthetic analogues stay labeled.

Analogue tests write a temporary synthetic catalog. They do not read the HackMIT catalog.

## Versions

TypeScript `7.0.2` and Vitest `5.0.2`, matching the workspace pins. The search uses Node's built-in `node:sqlite`. It does not add `better-sqlite3`.

From the repository root, with Node 24.21.0:

```text
pnpm install --frozen-lockfile
pnpm --filter @hackathon-atlas/cli typecheck
pnpm --filter @hackathon-atlas/cli test
```

`pnpm test` at the root also runs this package because `packages/*` is a workspace glob.
